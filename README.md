
# AssetManager

**A web-based hardware asset management platform built with Laravel.**

AssetManager is a personal software project focused on organizing, managing, and tracking hardware assets and their associated information through a centralized web interface.

The project explores full-stack web development, relational database design, authentication, API development, and maintainable application architecture.

> **Development status:** Work in progress. Features and interfaces are subject to change.

## Technology Stack

| Layer | Technology |
|---|---|
| Backend | PHP, Laravel 13 |
| Frontend | Blade, Bootstrap 5, JavaScript |
| Database | Laravel Eloquent ORM |
| Authentication | Laravel Breeze |
| API Authentication | Laravel Sanctum |
| Build Tooling | Vite, npm |
| Testing | PHPUnit |

## Project Structure

The application follows Laravel's MVC architecture, separating request handling, business logic, data models, and presentation.

Key areas of the project include:

- **Asset Management:** Routes for creating, viewing, editing, and deleting asset records.
- **User Accounts:** Authentication and profile-management functionality.
- **Dashboard:** A dedicated interface for authenticated users.
- **Tags:** A foundation for organizing assets.
- **Asset Sharing:** Public routes for exploring and viewing shared assets.
- **API:** A Sanctum-protected endpoint for asset-related requests.

Some functionality remains under active development.

## Project Goals

The long-term goal is to develop a flexible platform for managing personal hardware inventories, including computers, laptops, peripherals, and other electronic devices.

Planned areas of development include:

- Hardware component management
- Device specifications and lifecycle information
- Improved asset categorization and filtering
- Expanded API capabilities
- Automated device information collection
- Monitoring and reporting

These are development goals rather than claims of completed functionality.

## Development

The project is maintained as an independent learning and portfolio project.

Development focuses on practical software engineering concepts, including database relationships, application security, backend architecture, and user interface design.
